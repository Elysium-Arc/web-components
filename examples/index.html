What is Bare Components?
Bare Components is a collection of zero-dependency, framework-agnostic web components built for modern web applications.
How do I install it?
Install via npm: npm install bare-components
Is it accessible?

Toast

Stable

Success Error Warning Info With Action 
// Programmatic API

  type: 'success',
  title: 'Saved!',
  message: 'Your changes have been saved.',
  duration: 5000
});

// With actions
WcToast.show({
  type: 'info',
  title: 'Confirm',
  message: 'Are you sure?',
  actions: [
    { label: 'Yes', onClick: () => confirm() },
    { label: 'No' }
  ]
});

Remote Data (fetch from URL)

Reload Data 
<!-- Remote data: Just set src attribute! -->
<wc-table 
  src="https://api.example.com/users" 
  auto-columns
  searchable
  sortable 
  page-size="10">
</wc-table>

<!-- With custom columns -->
<wc-table src="https://api.example.com/users" columns="id,name,email" searchable>
</wc-table>

<!-- Reload data programmatically -->
<script>
  const table = document.querySelector('wc-table');
  
  // Listen to events
  table.addEventListener('load', (e) => console.log('Loaded:', e.detail.data));
  table.addEventListener('error', (e) => console.log('Error:', e.detail.error));
  
  // Reload data
  table.reload();
</script>
